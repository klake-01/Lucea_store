# Assets used by generated documents

## partner-logo.png

Drop the official 3D Print Maroc logo here, named exactly `partner-logo.png`,
and the order confirmation PDF picks it up automatically. A transparent PNG
roughly 400px wide works best.

Until that file exists the PDF renders the partner name typographically. We do
not ship a copy of a third party logo in this repository: it is their asset,
and reproducing it without the file they supply risks using an outdated or
unauthorised version of their mark.
